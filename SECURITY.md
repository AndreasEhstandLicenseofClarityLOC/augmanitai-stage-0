# Security Policy

## Scope

This repository is a **static content / metadata layer** (HTML pages, JSON-LD,
and text metadata) for the AUGMANITAI Research Programme. It contains no server,
no backend, no executable service, and processes no personal data. There is no
runtime attack surface beyond standard static web hosting (GitHub Pages).

## Reporting a vulnerability

If you discover a security or privacy issue — for example exposed credentials,
an unintended data leak, or a content-integrity problem — please report it
responsibly **before** disclosing publicly.

- **Contact:** ehstand.schule@gmail.com
- **Subject:** `SECURITY — augmanitai-stage-0`
- Please include: a description, affected file path(s) or URL(s), and steps to
  reproduce. Do not include exploit payloads against third parties.

We aim to acknowledge reports within a reasonable timeframe and to address
confirmed issues promptly. Coordinated, responsible disclosure is appreciated;
please allow time to remediate before any public write-up.

## Out of scope

- Best-practice/informational findings without a concrete impact.
- Volumetric or denial-of-service testing against the hosting provider.
- Issues in third-party platforms (e.g. GitHub Pages infrastructure) — report
  those to the respective provider.

## Data protection

No personal data is collected, stored, or processed by the static artifact.
See `/datenschutz/` for the GDPR/DSGVO notice and the hosting provider's privacy
statement.
