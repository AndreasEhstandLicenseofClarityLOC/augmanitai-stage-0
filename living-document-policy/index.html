Living-Document-Policy

The AUGMANITAI Compendium is a living document. Definitions, relations, and metadata may evolve continuously. This is intentional and explicit.

Versioning

Per-term semantic versioning (SemVer 1.0.0). Per-corpus version stamps (V1, V2, V3, V4, V4.1, V4.2, ...). Living-Stamp format: living-YYYY-MM-DD.

Change Tracking

All changes documented in /audit/. Multi-Hash-Provenance + Bitcoin-OpenTimestamps verankert kritische Snapshots. Concept-DOIs are immutable; new versions get separate Version-DOIs.

What is NOT changeable

Once a term is anchored (DOI + Bitcoin-OTS + Multi-Hash), the historical state is permanent. New iterations are additional, not destructive.

Living-Stamp-Update

On each significant content update: Living-Stamp updated site-wide. Format: living-2026-05-10
